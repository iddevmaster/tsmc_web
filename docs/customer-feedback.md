# Customer Feedback / Feature Requests

รายการ feedback จากลูกค้าที่รอการแก้ไข/พัฒนาเพิ่มเติม

## 2026-09-16

- [ ] **Import ข้อมูลข้ามฟอร์ม** — ตอนกรอกแบบฟอร์ม อยากให้ import ข้อมูลจากแบบฟอร์มอื่นได้ โดยระบบ fill
      เฉพาะช่อง (field) ที่ตรงกันระหว่างสองฟอร์มให้อัตโนมัติ
- [ ] **เชื่อมข้อมูล rollcall ก่อน/ระหว่าง/หลัง** — แบบฟอร์ม rollcall ทั้ง 3 ช่วง (ก่อนงาน/ระหว่างงาน/หลังงาน)
      ต้องเชื่อมข้อมูลกัน ไม่ต้องกรอกข้อมูลซ้ำ ให้กรอกต่อจากช่วงก่อนหน้าได้เลย
- [ ] **Auto-generate หมายเลขงาน** — ให้ระบบ gen หมายเลขงานให้อัตโนมัติในรูปแบบ `Year-Seq`
      (เช่น 2026-0001) แต่ผู้ใช้ยังสามารถแก้ไขเองได้
- [ ] **Autocomplete สำหรับประเภทคำตอบ** — เพิ่มประเภทคำตอบแบบใหม่ในแบบฟอร์มบิลเดอร์ ที่เป็น
      text field ให้กรอกเองได้ หรือจะเลือกจากตัวเลือกที่มีอยู่ก็ได้ (autocomplete)
- [ ] **ปุ่ม Clone แบบฟอร์ม** — เพิ่มปุ่ม clone/duplicate แบบฟอร์ม ในหน้าจัดการแบบฟอร์ม
      สำหรับคัดลอกแบบฟอร์มที่มีอยู่แล้วไปสร้างใหม่
